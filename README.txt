Global Lorebook Keeper v1.5.0
原作者：sleepyfish

在 SillyTavern 或 TauriTavern 中，让每条聊天独立使用自己的预设、提示词条目和额外的全局世界书。同一张角色卡的两条聊天可以共用一套预设，分别启用第一人称和第三人称。

安装与打开

1. 在酒馆的扩展面板选择「安装扩展」，输入仓库地址：
   https://github.com/Molly-0129/global-lorebook-keeper
   已安装本仓库版本的用户可从扩展管理中更新。
2. 点击输入框旁的魔法棒，在扩展菜单中选择「角色-预设-世界书绑定器」。也可以从扩展设置点击「打开绑定管理面板」。

角色默认预设

在「角色 ↔ 预设」中选择角色卡和预设，点击「保存角色绑定」。同一角色的新聊天默认继承这个预设；群聊只使用自己的聊天配置或手动预设。

按聊天绑定

1. 打开要配置的聊天，在绑定面板进入「当前聊天」。
2. 在「预设来源」选择「跟随角色绑定」「选择指定预设」或「跟随全局预设」。聊天指定优先，跟随全局预设会跳过角色绑定。跟随角色或指定 Chat Completion 预设时，提示词条目会显示实际的开启或关闭状态。保存时只记录与预设不同的开关，拨回预设原值会移除对应调整。
3. 按需勾选「额外启用的全局世界书」，再点「保存聊天绑定」。以后打开该聊天时，插件会读取这份配置。
4. 点「解除绑定」可清除这条聊天的配置。解除后重新跟随角色默认。没有角色默认时，恢复先前记录的手动预设。角色默认更换后，为旧预设保存的文风和人称开关只对原预设生效。

从酒馆预设面板记录条目

打开聊天并选择 Chat Completion 预设。在酒馆预设下拉框旁点链条图标，使用原有面板或条目管理扩展调整开关，再点勾号确认。插件把当前预设和开关保存为这条聊天的专属配置。插件里的「当前聊天」页可以继续查看和修改同一份配置，额外世界书仍使用原有聊天书单。点叉号可取消，切换聊天或预设会结束这次记录。

记录范围是条目开关。条目正文和排序请在预设管理界面维护。确认或取消后，酒馆原生开关恢复到开始记录前的状态。

共享世界书分组

在「预设 ↔ 世界书」中，可以把一组世界书关联到多个预设。插件会合并当前预设分组和当前聊天的额外书单，同一本书只启用一次。切换时会保留你原本手动勾选的全局世界书，只撤下由插件额外启用且当前用不到的书。原生「聊天世界书」仍由你在酒馆里管理。

在「更新识别与设置」中，可以扫描名称近似的新版预设，或开启自动继承，让新版预设加入原来的共享分组。

从旧版本升级

旧版预设与世界书的绑定会迁移到共享分组，扩展设置只保存一份书单。已有角色绑定重新作为默认值。v1.3.0 中已保存的聊天专属预设继续优先；已保存「沿用当前预设」和额外书单的聊天继续使用手动模式。未保存聊天配置的聊天默认继承角色预设。
