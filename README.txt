Global Lorebook Keeper
原作者：sleepyfish

为 SillyTavern 或 TauriTavern 的角色设定默认预设，也可以为每条聊天单独配置预设、提示词条目开关和额外的全局世界书。

安装与打开

1. 在酒馆的扩展面板选择「安装扩展」，输入仓库地址：
   https://github.com/Molly-0129/global-lorebook-keeper
   已安装的用户可在扩展管理中更新。
2. 点击输入框旁的魔法棒，在扩展菜单中选择「角色-预设-世界书绑定器」。也可以从扩展设置点击「打开绑定管理面板」。

角色默认预设

在「角色 ↔ 预设」中选择角色卡和预设，点击「保存角色绑定」。下方的「已保存的绑定关系」可以编辑或删除已有绑定。

按聊天绑定

1. 打开要配置的聊天，在绑定面板进入「当前聊天」。
2. 在「预设来源」中选择「跟随角色绑定」「选择指定预设」或「跟随全局预设」。指定的预设只作用于这条聊天，跟随全局时使用酒馆手动选择的预设。
3. 使用 Chat Completion 的角色绑定或指定预设时，可展开「提示词条目」查看和切换开关。保存时只记录与目标预设不同的值，拨回原值并保存即可清除该条调整。调整只对保存时的目标预设生效。
4. 按需勾选「额外启用的全局世界书」，再点「保存聊天绑定」。标题旁会显示已保存的预设和世界书。有生效的开关调整时，也会显示「已调整提示词条目」。

「解除绑定」会清除该聊天的专属配置。没有聊天专属配置时，优先跟随可用的角色绑定，其余情况跟随全局预设。群聊使用自己的聊天配置或全局预设。

从酒馆预设面板记录条目

打开聊天并选择 Chat Completion 预设。在酒馆预设下拉框旁点链条图标，调整开关后点勾号，把预设和开关差异保存到当前聊天。点叉号可取消，切换聊天或预设也会结束记录。结束后，酒馆面板的开关恢复到记录前。已保存的调整可以在「当前聊天」查看。

条目正文和排序仍在酒馆预设管理里编辑。

共享世界书分组

在「预设 ↔ 世界书」中，可让多个预设共用一组全局世界书。插件会把当前预设的书单与聊天额外书单合并去重，保留原本手动启用的全局世界书。酒馆原生的「聊天世界书」仍在酒馆里管理。

在「更新识别与设置」中，可以手动扫描名称近似的新版预设，或开启自动继承，让新版预设加入原来的共享分组。

从旧版本升级

旧版预设与世界书的绑定会迁移为共享分组。已有角色绑定和聊天专属预设会保留，旧版为聊天保存的「沿用当前预设」继续跟随全局预设。
